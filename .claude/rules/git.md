# Controle de Git e Commits

- Nunca execute `git commit` automaticamente.
- Nunca crie commits sem uma solicitação explícita do usuário.
- Nunca execute `git push` automaticamente.
- Nunca envie alterações para o repositório remoto sem autorização explícita.
- Você pode utilizar comandos Git para consultar o estado do repositório, verificar diferenças e analisar o histórico.
- Ao finalizar uma tarefa, informe quais arquivos foram modificados e aguarde novas instruções.
- Mesmo que a tarefa esteja concluída e todos os testes estejam passando, não realize commits por conta própria.
